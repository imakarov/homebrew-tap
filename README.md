# imakarov/tap

Homebrew tap for apps by [Ilya Makarov](https://imakarov.us).

```bash
brew install --cask imakarov/tap/shiftswitch
```

| Cask | Description |
|---|---|
| [shiftswitch](https://github.com/imakarov/shiftswitch) | Tap Shift to retype the last word in the other keyboard layout (ghbdtn → привет) |
